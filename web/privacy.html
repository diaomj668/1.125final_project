Privacy

Trip descriptions submitted in chat are sent to Anthropic. Place searches are sent to OpenStreetMap Nominatim. When Google routing is configured, trip coordinates, travel mode and (for transit) departure time are sent to Google. Map tiles are requested from OpenStreetMap. Requests pass through Cloudflare Tunnel. The application keeps rate limits and request calculations in memory and does not intentionally save chat messages. Service providers may process request metadata under their own policies. See the Google Privacy Policy. API keys are stored only on the server and are not sent to visitors.
